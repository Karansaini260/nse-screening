# Contributing to this project

Thanks for taking the time to contribute! 🎉 All types of contributions are
welcome — bug reports, feature ideas, documentation, tests, and code.

## Getting started
1. **Fork** the repo and clone your fork.
2. Create a branch: `git checkout -b feature/your-feature`.
3. Make your changes with **clear commit messages**.
4. Add or update **tests** for your change (if applicable).
5. Run the existing tests to make sure nothing breaks.
6. Open a **pull request** against `main`.

## Pull request checklist
- [ ] Descriptive title & linked issue (e.g. "Fixes #12")
- [ ] Tests pass locally
- [ ] No secrets / credentials committed
- [ ] Changelog entry added (if the project keeps one)

## Issue guidelines
- Search for an existing issue before opening a new one.
- Use the issue templates (bug report / feature request) where available.
- Include environment details and a minimal reproducer for bugs.

## Code style
- Follow the conventions already used in the repo.
- Keep changes focused and small — one concern per PR.

## Questions?
Open a discussion or ask in your PR. Thank you for improving this project!
